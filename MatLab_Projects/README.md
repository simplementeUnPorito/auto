# MatLab Projects

Scripts y proyectos MATLAB organizados por laboratorio, correspondientes al diseño y simulación de cada controlador.

## Estructura

```
MatLab_Projects/
├── Lab1/        # Scripts PID
├── Lab2/        # Lugar de raíces
├── Lab3/        # Bode / compensadores
├── Lab4/        # Truxal–Ragazzini
├── Lab5/        # Ubicación de polos
├── Lab6/        # Estimadores
├── Lab7/        # Control con integrador
├── Lab8/        # LQR / LQI
├── Lab9/        # Kalman / LQG
├── Repaso/      # Material de repaso y ejercicios
├── refi.m       # Script de referencia general
├── modelo.mat   # Modelo de la planta guardado
├── modeloSS.mat # Modelo en espacio de estados
└── Libro1.xlsx  # Tabla de datos/parámetros
```

> Los proyectos dentro de cada carpeta `LabN/` son los scripts usados para el **diseño y simulación** del laboratorio correspondiente. El código de **implementación en PSoC** se encuentra en [`../PSoC_Projects/`](../PSoC_Projects/).
