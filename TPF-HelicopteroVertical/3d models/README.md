# TPF — Modelos 3D

Modelos 3D impresos para la estructura física del helicóptero vertical.

## Archivos (formato `.gx` — Creality Slicer / GX)

| Archivo | Descripción |
|---------|-------------|
| `Brazo1.gx` | Brazo de soporte del motor, variante 1 |
| `Brazo2.gx` | Brazo de soporte del motor, variante 2 |
| `Brazo3.gx` | Brazo de soporte del motor, variante 3 |
| `Pivotes.gx` | Pivotes de deslizamiento sobre el riel |
| `SoporteBateria.gx` | Soporte para la batería LiPo |
| `Tapas.gx` | Tapas o cubiertas estructurales |

## Notas

- Los archivos `.gx` corresponden al formato de **Creality Slicer** (derivado de Cura).
- Imprimir con PLA o PETG. Relleno ≥ 40% recomendado para partes estructurales.
- Los pivotes deben ajustar al riel sin holgura excesiva para minimizar la fricción variable.
